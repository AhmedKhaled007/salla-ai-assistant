# Salla AI Assistant - Frontend

The React-based frontend for the Salla AI Assistant, built with Vite and Tailwind CSS.

## Features

- **AI-Powered Chat**: Interface for interacting with the Salla agent.
- **Salla Branding**: Tailored UI using official Salla colors and typography.
- **Responsive Design**: Optimized for different screen sizes.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Production

To build for production:
```bash
npm run build
```
